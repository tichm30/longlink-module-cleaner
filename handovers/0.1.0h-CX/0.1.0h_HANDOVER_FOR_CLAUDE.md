## Summary

This Module Cleaner batch wires the parity P0 cleanup path to the host-owned purge primitives instead of rebuilding destructive teardown inside the module.

Cleaner now creates per-module backup sets before purge handoff, exposes a host-purge execution payload with `backup_confirmed`, persists safety settings through the host settings registry, and adds review-only orphan table detection. The backup set records manifest, ownership snapshot, inventory, table rows, permission and role-permission rows, settings rows, navigation rows, package rows, and restore notes.

Purge execution still belongs to the host Addon Modules primitive. Cleaner prepares the backup, plan, evidence, and typed-confirm handoff required by the host.
