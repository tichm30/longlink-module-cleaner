## Summary

- Fixed the live MariaDB/MySQL 500 on `/admin/module-cleaner`.
- Root cause: `ResidueInventoryService::packageInventory()` selected `COUNT(*) as rows`, and MariaDB treats `ROWS` as a reserved keyword in this context.
- Fix: renamed query aliases to `package_rows` and `package_bytes`, then mapped them back to the existing inventory payload keys `rows` and `bytes`.
- Added regression coverage so the source cannot reintroduce `COUNT(*) as rows`.
