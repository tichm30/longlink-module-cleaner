# 0.1.0f-CX Update Log

## Scope

- Expanded Module Cleaner from a fragile placeholder into a snapshot-first cleanup console.
- Added Registry, Module Details, Dry-Run Plan, Orphan Tables, Backups, Quarantine, Logs, and Settings views.
- Added controller actions for registry inspection, module detail review, dry-run planning, residue sections, and settings save.
- Moved the addon menu registration to the host `platform_tools` parent with the `broom` icon.
- Kept destructive execution out of this release; `module_cleaner.purge` remains documented as a future gated purge boundary.
- Bumped `requires_host_min_version` to `0.7.9b-CX`.
